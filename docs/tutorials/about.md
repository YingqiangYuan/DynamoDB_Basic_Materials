# Course Overview

This course teaches the fundamental operations of Amazon DynamoDB — a cloud-native distributed NoSQL database — through hands-on Python scripts using the pynamodb ORM. Topics progress from basic CRUD and batch operations through query patterns, conditional writes, transactions, secondary indexes, and single-table design for one-to-many and many-to-many relationships.

After completing it, you can confidently perform DynamoDB read/write operations, design access-pattern-driven schemas, and explain how DynamoDB's key-value model differs from traditional relational databases — at an interview-ready level.
