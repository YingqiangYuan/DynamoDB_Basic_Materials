# Course Overview

This course teaches the fundamental operations of Amazon DynamoDB — a cloud-native distributed NoSQL database — through hands-on Python scripts using the pynamodb ORM. Topics progress from basic CRUD and batch operations through query patterns, transactions, secondary indexes, and single-table design.

After completing it, you can confidently perform DynamoDB read/write operations, design access-pattern-driven schemas, and explain how cloud-native distributed databases differ from traditional relational systems.
