# Course Syllabus

## Module 01 — DynamoDB + pynamodb Basic Operations

**Branch:** `01-Learn-This-Project`

**What it covers:** Hands-on introduction to Amazon DynamoDB using the pynamodb ORM. Progresses from a minimal POC through CRUD, batch operations, query vs scan, conditional writes, transactions, secondary indexes (GSI/LSI), and single-table design patterns for one-to-many and many-to-many relationships. All examples use a fin-tech credit card domain and run against a real AWS account.

**By the end you can:** Explain DynamoDB's key-based access model, implement common data operations with pynamodb, design partition/sort key schemas driven by access patterns, and articulate trade-offs between DynamoDB and relational databases at an interview level.

**Learning flow:** `/learn-this-project-absorb` → `/learn-this-project-quiz` → `/learn-this-project-elevate` → `/learn-this-project-interview` → `/learn-this-project-demo`
